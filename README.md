# Java Product Registration

Projeto simples em Java desenvolvido para praticar entrada de dados com `Scanner`, criação de variáveis e uso de tipos básicos.

## Funcionalidades

O programa permite cadastrar um produto informando:

- Nome do produto
- Quantidade em estoque
- Preço
- Disponibilidade do produto

Ao final, os dados cadastrados são exibidos no terminal.

## Conceitos praticados

- `Scanner`
- `String`
- `int`
- `double`
- `boolean`
- Entrada de dados pelo terminal
- Concatenação de variáveis
- Estrutura básica de um programa Java

## Como executar

Compile o arquivo:

javac Main.java
